# 🎬 Film & Actor Catalogue

A **C# Windows Forms application** for managing a catalogue of films and actors. Easily explore, search, and maintain film and actor records through a simple, user-friendly interface.

### Features
- **Film Management** — View, add, edit, remove, and rate films.
- **Actor Management** — View, search, add, edit, and remove actors.
- **Search & Explore** — Quickly find films and actors in the catalogue.
- **Film Ratings** — Rate films and keep track of your favourites.

### Tech Stack
- **Language:** C#
- **Framework:** Windows Forms (.NET)
- **IDE:** Visual Studio

### Getting Started
1. Clone this repository.
2. Open the solution (`.sln`) in Visual Studio.
3. Restore dependencies if required.
4. Build and run the application.
